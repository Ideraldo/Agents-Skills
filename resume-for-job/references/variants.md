# Resume versions

Replace this template with your own versions. Keep it short: Claude reads it on every run.

## Files

| Version | Language | File |
|---|---|---|
| Generic | English | `~/Resume/Generic/Your_Name_Engineer_CV.pdf` |
| Generic | (your language) | `~/Resume/Generic/Your_Name_CV_local.pdf` |
| Stack A (e.g. Node) | English | `~/Resume/StackA/Your_Name_StackA_CV.pdf` |
| Stack B (e.g. .NET) | English | `~/Resume/StackB/Your_Name_StackB_CV.pdf` |
| AI | English | `~/Resume/AI/Your_Name_AI_Engineer_CV.pdf` |

Tailored versions for a specific posting go in: `~/Resume/<company>/`

How the files are produced (optional): e.g. "edited in Word", or "generated by `build_resume.js`; facts are constants at the top of the script".

## Routing rules (first match wins)

1. Posting in your local language, or clearly a local company → local-language version
2. Stack A keywords at the top of the requirements → Stack A version
3. Stack B keywords, or a domain where your Stack B experience lives (e.g. finance) → Stack B version
4. LLM, RAG, embeddings, applied AI → AI version
5. Generic role or mixed stack with no dominant one → generic English version

## Compensation (optional)

Your floor and ask per work model (remote, on-site, contractor, international), so Claude can warn you when a posting is below it.
